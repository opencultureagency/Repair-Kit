# Essentials (repair-m01)

**Summary:**

> This Module contains all essential items needed for an every day application during trainings and events. It covers writing, charging, measuring, lighting and first aid including treatment of soldering burns to name some examples. 
> It is designed to always be the first go to module on top.

![repair-m01](../assets/repair-m01-front-image-withnumbers.jpg)

1. Headlight (3 light settings, includes 3 AAA batteries)
2. First aid kit (with burn ointment gel)
3. Scissors
4. 3× Small tubes of super glue
5. USB power adaptor (USB-A and USB-C)
6. Pen
7. Waterproof permanent marker
8. Measuring tape (3m)
9. Metal ruler (15cm)
10. Windproof lighter
11. USB stick (USB-A and USB-C)

# Basic Tools (repair-m04)

**Summary:**

> This Module contains all basic hand tools for manual work on repairing household and general devices. It is a basic set of tools to help you with most tasks. 
> It is meant to stay in the bottom of the case to serve as a counter weight for repair-m01 in the lid.

![repair-m04](../assets/repair-m04-front-image-withnumbers.jpg)

1. Mini duct tape
2. Mini caliper 
3. Combination screwdriver handle with bit set (extension, socket: ¼")
4. 2× Bit set (Torx bits, socket: ¼", magnet for better screw-driving)
5. Adjustable wrench
6. Pointed pliers
7. Screwdriver power tester
8. Cutter

# Soldering (repair-m02)

**Summary:**

> This Module has all basic components to solder electronics, measure circuits and test the main elements of USB devices. It also comes with most relevant soldering material and heat-shrink tubes to get you started. (It does not replace a soldering station and still requires 230V)

![repair-m02](../assets/repair-m02-front-image-withnumbers.jpg)

1. USB voltmeter (USB-A)
2. Soldering tip cleaner
3. Desoldering braid
4. Soldering iron (variable temperature)
5. Soldering flux
6. Soldering iron holder incl. set of various heat shrink tubing pieces
7. Solder
8. Multimeter incl. manual
